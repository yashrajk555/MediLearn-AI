# MediLearnAI

MediLearnAI is a healthcare-oriented web application that guides users through a symptom assessment questionnaire and provides predefined care suggestions, home remedies, and warning-sign checks.

## Features

- Selection of multiple symptoms
- Follow-up questions about symptom severity, duration, and associated symptoms
- Predefined care and remedy information
- Basic warning-sign detection
- Results page and assessment restart functionality

## Technologies Used

- Python
- Flask
- HTML templates
- Static web assets (CSS, JavaScript, and images, where included)

## Supported Symptoms

Headache, fever, cough, cold, stomach pain, nausea, sore throat, fatigue, body pain, and diarrhea.

## Getting Started

1. Install Python 3.
2. Install the dependencies listed in `requirements.txt`.
3. Run the application using:

   `python app.py`

4. Open the local URL displayed in the terminal.
